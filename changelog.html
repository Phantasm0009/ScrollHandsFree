What's New

Short release notes for recent ScrollHandsFree updates.

1.3.0

  • Moved from always-injected content scripts to on-demand injection.
  • Added context menu actions, diagnostics, per-site settings, and local data controls.
  • Expanded the HUD with progress, time remaining, speed, direction, pause, and stop.
  • Added command aliases, voice debounce, Reading Focus sizing, and natural-break pausing.
  • Added welcome, sample reading, changelog, and privacy pages.

1.2.0

  • Redesigned the popup as a compact reading remote.
  • Added voice setup disclosure, language selection, privacy cues, and on-page HUD auto-hide.
  • Fixed status rendering so object responses no longer appear as "[object Object]".
