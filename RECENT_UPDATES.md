## Recent Updates

### 1.3.0

- On-demand injection replaces always-on page scripts.
- Context menu actions added.
- On-page HUD now shows progress, speed, direction, time remaining, and active controls.
- HUD can be dragged and its position is stored locally per site.
- Heading and content-break pause checks are throttled to reduce jank risk on heavy pages.
- Page tools now include next-heading and back-one-paragraph navigation.
- Reading Focus supports adjustable band height and dim opacity.
- Per-site settings, resume positions, voice aliases/disabled commands, diagnostics, import/export, and clear-local-data controls added.
- Accessibility hints are documented as simple local checks only, not WCAG compliance.
- Welcome, sample reading, privacy policy, changelog, and store listing refresh notes added.

### 1.2.0

- Popup redesigned as a calm reading remote.
- Voice setup and privacy copy added.
- Voice language selection added.
- Status rendering fixed so objects are not displayed as `[object Object]`.
