ScrollHandsFree Manual Test Page

This page exists so the extension can be tested on predictable long-form content without relying on a third-party website.

Checklist

  • Start, pause, resume, and stop scrolling.
  • Try Slow, Reading, Fast, and Skim speed presets.
  • Toggle Reading Focus.
  • Enable the on-page HUD and drag it.
  • Use Jump to next heading and Back one paragraph.
  • Try Choose scroll area on the nested panel below.

Article section one

Hands-free scrolling should feel predictable. The page should move at a steady pace, pause when requested, and stop cleanly at the end. A good reading tool should never fight the user.

The popup should reflect the active tab. If you switch tabs and come back, the status should still make sense for this page.

Reading Focus should dim the surrounding content without covering text or making the page feel heavy.

Nested scroll area

Use Choose scroll area, then click inside this panel. The extension should scroll this panel rather than the full page.

Nested heading one

This is nested content inside an overflow container. It should help test smart scroll-area detection.

Documentation sites and web apps often use this kind of layout, with a sidebar or fixed frame around the main reading pane.

Nested heading two

The selected container should keep moving while the outer page stays mostly still.

If this panel does not scroll, use the context menu action to choose the scroll area again.

Nested heading three

Progress and estimated time remaining should update while this panel scrolls.

End-of-container behavior should match the selected end behavior in the popup.

Nested heading four

This is the final nested section. The panel is intentionally long enough to exercise the scroll engine.

Article section two

Manual scrolling should temporarily pause auto-scroll when that option is enabled. This makes the extension feel cooperative instead of stubborn.

Heading pauses should trigger near visible section headings, but they should not repeat constantly on the same heading.

Time remaining is an estimate based on scrollable distance and current speed, so small layout changes can affect it.

Article section three

Voice commands are optional. If enabled, test short phrases such as start, pause, stop, faster, slower, up, down, top, bottom, focus on, and focus off.

The console should not print recognized spoken phrases. Privacy-sensitive feedback should stay generic.

The extension should still work without microphone permission.

End of page

This is the bottom of the manual test page. Verify that reached-end behavior, stop, loop, and reverse work as expected.
