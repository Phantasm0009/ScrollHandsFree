Voice Command Test Page

This page is for manual voice-command testing. It does not run any test script and does not collect audio.

Before testing

  1. Load the extension in Chrome.
  2. Open the popup on this page.
  3. Enable Voice Commands.
  4. Choose the voice language in Options if you are testing a non-default language.
  5. Watch the popup or HUD for generic command feedback.

English commands

Try short phrases first:

start pause stop faster slower up down top bottom

Focus commands

focus on focus off bigger focus smaller focus

Custom aliases

Add a custom alias in Options, then say it on this page. The extension should match the alias without logging the spoken phrase to the console.

Expected privacy behavior

  • The page should show only generic command feedback.
  • The console should not print recognized spoken phrases.
  • Microphone access should be optional and limited to voice commands.
  • Auto-scroll should still work if microphone permission is denied.

Long content

Use this section to keep the page scrollable while testing voice commands. Repeat start, pause, faster, slower, and stop while observing the popup state.

The reading controls should continue to respond after tab switches, popup reopenings, and HUD hide/show changes.

At the end of the page, verify that the selected end behavior is respected.
