Disable Commands

Command Test

Type a phrase to check which local command it would match. This does not use the microphone.

Voice commands are handled by your browser. ScrollHandsFree does not collect, store, or transmit audio.

What's New

  • Voice setup now explains microphone use before enabling voice commands.
